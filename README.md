**B105 Assignment**

**Project: Super Store Sales and shipping analyzation through R**

**Project Description:** My repository contains all the work for the B105 project. I have used R to clean the data, summarize the data, understanding the sales trend through chart and and ran different stats test to see how different factor affect the performance of Business.

**Dataset source and brief description:**

**Dataset source:**<https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting>

**Brief Description**: I have chosen a retail store sales dataset that covers information regarding sales, shipping options and order id. For accuracy of the results i cleaned the data first and then ran the tests.

**Analysis description:**

**Data cleaning:** checking for wrong column and rows error check if their is any to make the dataset ready for project.

**Data exploration:** creating graphs and table to findout the pattern in sales and shipping.

**Statistical testing:** i chosed anova as i have more than two categories. By this i checked that if different shipping methods have effect in sales. I got result of 0.965 which showed their is no significant difference. Checking diagnostics: looking at residual plots to make sure our model makes sense.
